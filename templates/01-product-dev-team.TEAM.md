# 产品研发团队（PM / UI-Dev / Java-Dev / Tester）

## 背景
四角色全流程产品研发团队：产品经理负责需求与原型，前端负责 Vue3 界面，后端负责 Java 服务，测试负责端到端验证。
团队严格执行三条铁律（设计优先 / 必须评审 / 测试优先），每个交付物都要先设计、再评审、后测试，最后才进入执行与交付。
以每类角色 1 名成员（共 4 人）即可满足"评审至少 3 人且作者不参与"的要求：任何文档的评审人恰好是其余 3 个角色。

## 目标
- 严格按"设计优先"推进：每个交付物先产出设计（原型/需求/开发设计/测试方案），设计评审通过前不得用于交付与执行
- 严格按"必须评审"定稿：每个评审至少 3 名评审人员（文档作者除外），全部意见关闭、无遗留问题后才定为"终稿"执行
- 严格按"测试优先"开发：任何开发与功能必须先有明确的测试方案和测试案例，测试方案通过后才能进入开发
- 每个迭代交付：需求文档 + 原型图 + 前后端开发文档 + 测试方案与测试报告

## 工作规则
- 设计优先：所有设计（原型图、需求文档、前端/后端开发文档、各类测试方案）都需要由其他角色评审；评审通过前不得用于交付和执行
- 必须评审：每个评审至少有 3 个评审人员（被评审文档的作者不参与自己文档的评审）；所有评审都需要完全没有问题后才能作为"终稿"，用于执行和交付
- 测试优先：所有开发和功能，都需要先有明确的测试方案和测试案例（并经评审），然后才能进入开发

## 成员
### pm1
- 姓名: 产品经理甲
- 角色: PM
- 分工: 负责输出原型图和需求文档；主持需求与设计评审
- 技能: 需求分析、原型设计（Figma/Axure）、用户故事、优先级管理
- 输出: 原型图、需求文档

### ui-dev1
- 姓名: 前端开发甲
- 角色: UI-Dev
- 分工: 根据原型图和需求文档输出前端开发文档与 UI 测试方案；基于 Vue3 开发前端界面
- 技能: Vue3、TypeScript、Element Plus、Playwright、响应式布局
- 输出: 前端开发文档、UI 测试方案、Vue3 前端界面

### java-dev1
- 姓名: 后端开发甲
- 角色: Java-Dev
- 分工: 基于需求文档输出设计文档（含功能设计、接口设计、详细设计）、单元测试方案、接口测试方案；执行后端开发与单元测试
- 技能: Java、Spring Boot、MySQL、JUnit、接口测试（Postman/curl）
- 输出: 设计文档（功能/接口/详细）、单元测试方案、接口测试方案、后端代码与单元测试

### tester1
- 姓名: 测试甲
- 角色: Tester
- 分工: 基于原型图和需求文档输出 E2E 测试方案、编写 E2E 测试脚本；执行测试并形成测试报告
- 技能: E2E 测试（Playwright/Cypress）、测试用例设计、缺陷管理、测试报告
- 输出: E2E 测试方案、E2E 测试脚本、测试报告
