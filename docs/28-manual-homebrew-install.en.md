# Installing & releasing teamx via Homebrew (brew install teamx)

> Status: **implemented & verified** (v0.2.0 installed via `brew install caishu97/tap/teamx`)
> Audience: users who want teamx via Homebrew / maintainers who cut releases

---

## 1. User installation

```bash
brew tap caishu97/tap
brew install caishu97/tap/teamx
# afterwards you can just run: brew install teamx (once the tap is present)
```

- macOS (Apple Silicon / M1+): installs the `aarch64-apple-darwin` binary
- Linux x86_64 / arm64: also supported (formula picks the right tarball per os/arch)
- **Windows does not use brew**: use the `teamx-windows-x86_64.zip` from the enterprise build instead

## 2. Architecture

```
brew install caishu97/tap/teamx
        │
        ▼
Public tap repo   caishu97/homebrew-tap
  Formula/teamx.rb    ← download URL + sha256 + os/arch branches
        │
        ▼ anonymous download
Public Release assets  caishu97/homebrew-tap/releases/tag/v0.2.0
  teamx-macos-arm64.tar.gz
  teamx-linux-x86_64.tar.gz
  teamx-linux-arm64.tar.gz
```

**Why binaries live on the public tap instead of the enterprise repo**:
the enterprise source repo `caishu97/teamx-enterprise` is **private**, so its
Release assets cannot be downloaded anonymously by brew (GitHub returns 404 for
private repo assets). Binaries are therefore mirrored to the **public
homebrew-tap repo** (formula metadata + binaries are public; enterprise source
is not shipped there).

## 3. Tarball layout (generated by release.yml)

Each tarball unpacks to:

```
teamx-<version>/
  bin/teamx          ← single static binary (rusqlite bundled, no external libs)
  LICENSE            ← proprietary license
```

Homebrew auto-chdirs into `teamx-<version>/`; the formula runs
`bin.install "bin/teamx"`.

## 4. Release SOP (maintainer)

### 4.1 Tag to trigger the build

```bash
git tag v0.2.0            # version must match Cargo.toml / formula version
git push enterprise-origin v0.2.0
```

Triggers `.github/workflows/release.yml`:
- 3 platforms in parallel: macos-arm64 (macos-14), linux-x86_64 (ubuntu-latest), linux-arm64 (ubuntu-24.04-arm)
- each builds `teamx-<platform>.tar.gz`
- uploads to the **private** enterprise release (v0.2.0)
- if `TAP_RELEASE_TOKEN` (PAT with repo scope) is configured, mirrors to the **public** homebrew-tap release

### 4.2 Mirror tarballs to the public tap (manual fallback if no PAT)

```bash
cd /tmp
gh release download v0.2.0 --repo caishu97/teamx-enterprise \
  --pattern "teamx-*.tar.gz" --clobber

# upload to the public tap release (create it first)
gh release create v0.2.0 --repo caishu97/homebrew-tap \
  --title "teamx v0.2.0 binaries" \
  --notes "Pre-built teamx binaries for Homebrew"   # first time only
gh release upload v0.2.0 teamx-*.tar.gz --repo caishu97/homebrew-tap
```

### 4.3 Update the formula sha256

```bash
shasum -a 256 teamx-macos-arm64.tar.gz teamx-linux-x86_64.tar.gz teamx-linux-arm64.tar.gz
```

Fill the 3 hashes back into `Formula/teamx.rb` in `caishu97/homebrew-tap`
(also bump `version`), then commit & push:

```bash
cd /tmp/homebrew-tap
# edit Formula/teamx.rb: version = "X.Y.Z" + the three sha256
git add Formula/teamx.rb
git commit -m "teamx vX.Y.Z: update sha256"
git push origin main
```

### 4.4 Verify

```bash
brew untap caishu97/tap && brew tap caishu97/tap   # refresh the tap
HOMEBREW_NO_REQUIRE_TAP_TRUST=1 brew install caishu97/tap/teamx
teamx --version
```

## 5. Tap trust (Homebrew 6+)

Newer Homebrew adds a trust check for third-party taps. On first install users
see a prompt; two options:
- Trust the whole tap: `brew trust caishu97/tap`
- Skip once: `HOMEBREW_NO_REQUIRE_TAP_TRUST=1 brew install caishu97/tap/teamx`

(Trust is one-time; afterwards plain `brew install teamx` works.)

## 6. Known limitations

- **version is a manual sync point**: every release must align git tag /
  Cargo.toml / formula version.
- **sha256 cannot be fully automated**: it only exists after the build; the
  formula must be updated.
- **Homebrew installs only the CLI binary**: the opencode plugin (`/team`
  commands, agent routing) still needs `install.sh` or `opencode plugin install`.
- **Xcode**: on macOS, brew may warn about an outdated Xcode/CLT; that is a
  Homebrew environment notice and does not affect the teamx binary install.
