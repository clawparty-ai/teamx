# 需求：轻量任务看板（Kanban Lite）

> 本文件是团队 demo 的"需求输入"。owner 基于它产出设计方案，reviewer 对方案进行评审。

## 背景

团队需要一个**本地优先、无外部服务依赖**的轻量任务看板工具，供 3~5 人小团队跟踪任务。要求单机即可用、可维护、易扩展，暂不需要多用户登录与权限系统。

## 功能需求

1. **任务管理**
   - 创建 / 编辑 / 删除任务：标题、描述、优先级（P0/P1/P2）、标签、负责人、截止日期。
   - 看板视图：任务按状态列展示（待办 → 进行中 → 评审中 → 已完成），支持拖拽或命令切换状态。
2. **列表与筛选**
   - 按负责人、优先级、标签、状态过滤；支持按关键字搜索。
3. **数据持久化**
   - 本地存储，退出重开后数据不丢失；文件格式便于备份（建议纯文本/JSON）。
4. **CLI 为主 + 最小 Web 视图**
   - CLI：`kanban add/todo/done/status/list ...` 核心操作。
   - Web：只读面板（可选），展示看板状态，无需编辑能力。
5. **协作（可选，二期）**
   - 预留多人同步能力（文件级 diff 或简单合并），本期不实现。

## 非功能需求

- **技术栈**：Go 或 Rust 均可，作者自选；CLI 为单二进制，无运行期依赖。
- **存储**：单文件（JSON 或 SQLite），原子写入，避免损坏。
- **性能**：1000 任务以内操作无感知延迟。
- **测试**：核心逻辑（任务状态转换、筛选、存储往返）有自动化测试。

## 验收标准

1. 能用 CLI 完整走通一个任务生命周期：创建 → 指派 → 开始 → 评审 → 完成。
2. 退出重开后数据完整恢复。
3. 1000 任务规模下，`list --filter` 响应 < 100ms。
4. 提供 README 说明安装与常用命令。
