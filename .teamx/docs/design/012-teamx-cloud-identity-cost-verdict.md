## A. 第三段：身份与安全（**已裁决**）

| # | 结论（推荐 + 团队一致） | 团队补充（一并采纳） |
|---|---|---|
| **D8** | **合一**：Teamx Cloud 登录与 #8 GitHub App 用同一个 GitHub App；user OAuth 答"人是谁"→ 绑 `users.id`；installation webhook 答"哪些 repo 事件"→ 走 #8 事件桥 | ① **token 用途分离**：user token 只读身份/仓库列表，**绝不执行 agent 动作**（agent 动作一律 installation token + 归因 device member）；② **`users.id` 作为「人」的锚点**，OAuth / join token / workspace 上报三处统一（多设备同人多座位已验证）；③ 负例：user token 调 agent 动作 → 拒 + 审计；伪造他 installation 事件 → 拒；④ App private key 不落 node |
| **D10** | **仅元数据 + 租户授权式 break-glass** | ① 元数据字段清单必须是**封闭枚举（fail-closed）**——不在清单即不可见（与二维白名单同纪律）；② 授权**短 TTL + 单次 + 落审计**；③ 事后告警**通知租户全部 lead**（不只 owner）；④ 审计流独立于租户可控台账（否则被审计方可改审计）；⑤ 负例：平台无授权读正文 → 拒 + 审计 |
| **D4** | **B 为主（本地=用户设备）+ A 可选（Pod 内）**，C 仅降级兜底 | ① B 链路**超时语义要显式写**：xiaods 区分的「白板僵死 vs 慢初始化」两种失败模式在 B 链路全程都可能发生；② 验收三件套（liveness / 首字节预算 / 大包完成率）**覆盖全程**而非只测提供端；③ E2E 断言 forward 目标 == 上报字段（与 D3 同一"上报唯一源"纪律） |
| **D17** | **v1 只有默认档** + **可证伪的如实声明**；gVisor 后置 | ① 声明必须**列死执行集**（共享内核 + PSA(restricted) + seccomp + 只读根 + 默认禁出网 + 封 IMDS）**与非目标**（不防内核侧信道）；② 「同信任域」具体化：同一组织成员、共享同一套合规要求（同公司多团队=是，对外开放=否）；③ gVisor 档给出**准入条件**（何种威胁/负载触发），否则是 vapor 档位 |

## B. 第四段：成本 · 体验 · 过程（**已裁决**）

| # | 裁决 |
|---|---|
| **D14** | **v1 不做成本兜底**（不设配额/额度/最小套餐）—— k8s 宿主机数量由 owner 直接控制，容量风险在资源层已人为限制。**（design/017 SD-11 维持：配额与 TCoin 双轨分工，互不触发）** |
| **D15** | ~~v1 不做计量~~ → **口径修订（design/017 SD-8，2026-09-24）**：**v1 做计量但不计费、不阻断** —— 以 `activity`+`model_pricing` 为唯一计量源折算 TCoin 落账与展示；**不阻断任何操作**（余额不足只软告警）。活跃秒/member-小时/存储口径仍不做（017 SD-7 定为 v2）。 |
| **D16** | **冷启动全异步**：member 先建、秒级可达、可派任务；UI 显示"准备中"；三段进度（调度+拉镜像 / workspace 恢复 / agent 热身）可见；"首次同步等待"仅可选、不默认。 |
| **D18** | 四段裁决落档后关闭第二轮；**第一轮脑爆 #9 已关闭**（37 帖 + 6 条 directions + `forced` 审计）。 |
